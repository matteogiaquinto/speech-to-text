Get started

Browser speech-to-text, without the backend.

Add private Whisper dictation to any input, textarea, or command bar. Audio and transcription stay in the browser.

✦
Framework agnostic

The package exposes a small TypeScript API and leaves the UI to your application.

01

Installation

Install the package with the package manager your project uses.

Terminal
$ pnpm add @matteogiaquinto/speech-to-text

This package is browser-only at runtime, but importing it from an SSR build is safe. Browser APIs are accessed only when lifecycle methods run.

02

Quick start

Create one long-lived instance, prepare the model after explicit user intent, then start and stop recording.

TypeScript
import { createSpeechToText } from "@matteogiaquinto/speech-to-text";

const speech = createSpeechToText({
  language: "fr",
  model: "whisper-base",
});

await speech.prepare();
await speech.start();

// The user speaks.
const text = await speech.stop();

console.log(text);
speech.dispose();

Core concepts

A predictable lifecycle

1

Prepare

Download or restore the model without opening the microphone.

speech.prepare()
2

Record

Request microphone access and begin a new recording.

speech.start()
3

Transcribe

Stop capture, run Whisper locally, and receive plain text.

speech.stop()

Status updates

Use onStatus to map the runtime lifecycle to your own loading, recording, and error UI.

TypeScript
const speech = createSpeechToText({
  onStatus(status) {
    // idle | loading | ready | recording
    // transcribing | error
    renderVoiceState(status);
  },
});

Models & languages

French and whisper-base are the defaults. Choose a model once when creating the instance; recreate it only when the user intentionally changes models.

Model Speed Accuracy Best for
whisper-tiny Fastest Lower Lightweight dictation
whisper-base Fast Good Balanced default
whisper-small Slower Better Higher-quality short dictation
whisper-large-v3-turbo Heavier Higher Powerful devices

Model cache

Model files are stored in browser origin-private storage and are normally reused on later visits. By default the wrapper keeps only the selected model and cleans stale unreferenced cache files.

browser profile+site origin=model cache
i
Cache scope matters

Private browsing, another origin or profile, cleared site data, or a different device may require another download. Use cachePolicy: "keep-all" only when several models must remain cached. dispose() does not clear the selected cached model.

Insert transcripts safely

Preserve existing text. Insert at the selection when practical, or append using exactly one separating space. Controlled fields should always use the framework's state update mechanism.

TypeScript
const text = await speech.stop();

const nextValue = currentValue.trim()
  ? `${currentValue.trimEnd()} ${text}`
  : text;

setValue(nextValue);

Cleanup

Reuse the same instance across successful recordings. Dispose it only when the owning feature permanently unmounts.

Example
return () => {
  speech.dispose();
};

Reference

API reference

createSpeechToText(options?)SpeechToText

Creates an isolated speech-to-text instance.

language?: string
BCP-47 language code. Default: "fr".
model?: ASRModel
Whisper model. Default: "whisper-base".
preload?: "after-load" | "on-demand"
Default: "after-load". Background preparation starts only after page load and idle time.
cachePolicy?: "single-model" | "keep-all"
Default: "single-model". Prevents model caches from accumulating across model changes.
onStatus?: (status) => void
Receives coarse lifecycle updates.
prepare()Promise<void>

Downloads or initializes the selected model without opening the microphone. Calls are idempotent and single-flight.

isPrepared()boolean

Reports whether the model is initialized in this runtime.

start()Promise<void>

Ensures the model is prepared, then requests microphone access and begins a recording.

stop()Promise<string>

Stops capture, transcribes locally, and returns trimmed plain text.

dispose()void

Stops tracks, cancels in-flight transcription, and releases runtime resources.

Errors

Failures are exposed as SpeechToTextError, MicrophoneError, or TranscriptionError. The original error is available through cause.

!
Keep typing available

Return to the compact microphone and use your product's normal non-blocking error UI.

Browser requirements

Production microphone access requires HTTPS. Localhost is a secure context for local development. Runtime support inherits the WebGPU, WebCodecs, and WASM constraints of browser-whisper.

Threaded WASM can require cross-origin isolation. Add these headers only when your deployment needs that fallback, and test all third-party resources afterward.

HTTP headers
Cross-Origin-Embedder-Policy: require-corp
Cross-Origin-Opener-Policy: same-origin
